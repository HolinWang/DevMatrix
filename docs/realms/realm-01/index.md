# 第一境【炼气期】（炼器入门）

以HTML铸道骨，语义标签立乾坤；CSS为血肉，盒模型塑金身，Flex/Grid筑仙基。JS通经脉，闭包凝神识，事件循环悟天道。破布局塌陷之劫，降变量提升心魔。手写静态页证道，W3C雷劫淬凡躯。

## 本境大纲

- **目标**：掌握语义化 HTML、盒模型与基础布局
- **核心概念**：语义标签、盒模型、Flex/Grid、响应式、JavaScript基础
- **修炼章节**：
  - [修炼 01：炼气入门](/lessons/lesson-01/) - 语义HTML基础
  - [修炼 02：呼吸吐纳](/lessons/lesson-02/) - CSS盒模型与布局
  - [修炼 03：铸体要诀](/lessons/lesson-03/) - Flexbox与Grid布局
  - [修炼 04：经脉疏通](/lessons/lesson-04/) - JavaScript基础语法
  - [修炼 05：神识凝聚](/lessons/lesson-05/) - 闭包与作用域
  - [修炼 06：天道循环](/lessons/lesson-06/) - 事件循环与异步编程

## 修炼要点

- 掌握HTML语义化标签的正确使用
- 理解CSS盒模型、定位与布局
- 熟练运用Flexbox和Grid进行响应式布局
- 掌握JavaScript基础语法和核心概念
- 理解闭包、作用域和事件循环机制
- 能够手写静态页面并通过W3C验证

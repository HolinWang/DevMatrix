# 修炼 01：炼气入门

## 语义HTML基础

[← 返回上一节](/) | [回首页](/)

以语义 HTML 打牢根基，页面为体，语义为骨。可在此处补充炼气期的详细练习与代码示例。

### 修炼要点

- 理解HTML语义化的重要性
- 掌握常用语义标签的使用
- 学会构建语义化的页面结构

### 核心概念

#### 语义化标签

```html
<!-- 页面结构 -->
<header>页面头部</header>
<nav>导航菜单</nav>
<main>主要内容</main>
<aside>侧边栏</aside>
<footer>页面底部</footer>

<!-- 内容结构 -->
<article>独立文章</article>
<section>内容区块</section>
<h1>到<h6>标题层级</h1>
```

#### 表单语义化

```html
<form>
  <fieldset>
    <legend>表单分组</legend>
    <label for="name">姓名：</label>
    <input type="text" id="name" name="name">
  </fieldset>
</form>
```

### 实战练习

1. 创建一个语义化的个人博客页面
2. 使用正确的标签结构组织内容
3. 确保页面的可访问性

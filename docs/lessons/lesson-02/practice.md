## 📋 练习内容概览

### 1. 标准盒模型 vs IE盒模型
- 直观对比两种盒模型的差异
- 查看实际尺寸计算
- 理解`box-sizing`属性的作用

### 2. 不同Display属性的盒模型差异
- **块级元素**：占满父容器宽度，上下margin有效
- **行内元素**：宽度由内容决定，只有左右margin有效
- **行内块元素**：结合了块级和行内元素的特性

### 3. Padding、Margin、Border 间距控制
- **Padding**：控制内容与边框之间的距离
- **Margin**：控制元素与其他元素之间的距离
- **Border**：为元素添加边框和视觉效果

### 4. 实际布局应用
- 完整的页面布局示例
- 侧边栏 + 主内容区域的经典布局
- 响应式设计适配

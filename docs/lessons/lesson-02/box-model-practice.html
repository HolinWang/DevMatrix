1. 标准盒模型 vs IE盒模型

理解两种盒模型的差异：标准盒模型的width只包含内容，IE盒模型的width包含padding和border。

标准盒模型
实际宽度： 200px + 40px(padding) + 6px(border) = 246px
实际高度： 100px + 40px(padding) + 6px(border) = 146px
IE盒模型
实际宽度： 200px (包含padding和border)
实际高度： 100px (包含padding和border)
/* 标准盒模型 */
.standard-box {
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 3px solid #2c3e50;
}

/* IE盒模型 */
.ie-box {
  box-sizing: border-box;
  width: 200px;
  height: 100px;
  padding: 20px;
  border: 3px solid #2c3e50;
}

  display: block;
  width: 100%; /* 占满父容器宽度 */
  margin: 10px 0; /* 上下margin有效 */
}

/* 行内元素 */
.inline-element {
  display: inline;
  width: auto; /* 无效 */
  margin: 10px 0; /* 只有左右margin有效 */
}

/* 行内块元素 */
.inline-block-element {
  display: inline-block;
  width: 150px; /* 有效 */
  margin: 10px; /* 有效 */
}

3. Padding、Margin、Border 间距控制

练习使用不同的间距属性来控制元素间的距离和视觉效果。

Padding 内边距

这个元素有30px的内边距，内容与边框之间有较大空间。

作用：控制内容与边框之间的距离

Margin 外边距

这个元素有30px的外边距，与其他元素保持距离。

作用：控制元素与其他元素之间的距离

Border 边框

这个元素有5px的绿色边框，圆角为15px。

作用：为元素添加边框和视觉效果

/* Padding 示例 */
.padding-demo {
  padding: 30px;
  border: 2px solid #e74c3c;
}

/* Margin 示例 */
.margin-demo {
  margin: 30px;
  border: 2px solid #3498db;
}

/* Border 示例 */
.border-demo {
  border: 5px solid #2ecc71;
  border-radius: 15px;
}

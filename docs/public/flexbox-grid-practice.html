💡 学习提示

🎯 学习要点

  • Flexbox：适合一维布局，如导航栏、卡片列表
  • Grid：适合二维布局，如页面整体结构、图片画廊
  • 响应式：使用媒体查询和相对单位实现适配
  • 结合使用：页面用Grid，组件用Flexbox

# CSS盒模型实战练习

## 📖 练习说明

这个HTML页面是专门为学习CSS盒模型而设计的交互式练习工具。通过实际的代码示例和可视化效果，帮助你深入理解CSS盒模型的核心概念。

## 🎯 学习目标

通过完成这个练习，你将掌握：

1. **盒模型组成**：理解content、padding、border、margin的关系
2. **盒模型类型**：标准盒模型与IE盒模型的区别
3. **Display属性**：block、inline、inline-block的不同行为
4. **间距控制**：合理使用padding、margin、border进行布局
5. **实际应用**：将盒模型知识应用到真实页面布局中

## 📋 练习内容

### 1. 标准盒模型 vs IE盒模型
- 直观对比两种盒模型的差异
- 查看实际尺寸计算
- 理解`box-sizing`属性的作用

### 2. 不同Display属性的盒模型差异
- **块级元素**：占满父容器宽度，上下margin有效
- **行内元素**：宽度由内容决定，只有左右margin有效
- **行内块元素**：结合了块级和行内元素的特性

### 3. Padding、Margin、Border 间距控制
- **Padding**：控制内容与边框之间的距离
- **Margin**：控制元素与其他元素之间的距离
- **Border**：为元素添加边框和视觉效果

### 4. 实际布局应用
- 完整的页面布局示例
- 侧边栏 + 主内容区域的经典布局
- 响应式设计适配

## 🛠️ 使用方法

1. 在浏览器中打开 `box-model-practice.html`
2. 仔细阅读每个部分的说明和代码示例
3. 尝试修改CSS代码，观察效果变化
4. 使用浏览器开发者工具检查元素的实际尺寸
